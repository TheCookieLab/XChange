# XChange Stream Kraken (legacy Spot WebSocket v1)

Deprecated legacy Spot WebSocket v1 adapter. Use `xchange-stream-kraken-v2` for all new
integrations; see the migration section of the [Kraken family guide](../docs/kraken-family.md).

This module exposes Spot order book, ticker, and trades over the v1 WebSocket protocol with
checksum support. It is kept for the repository compatibility grace period and will be
removed in a later scoped change. No new capabilities will be added here.
